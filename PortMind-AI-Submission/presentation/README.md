```
         Team Name | IBM Bob AI Innovation Hackathon 2026 | Track: AI

         Port congestion costs: $15,000–$50,000/day demurrage per vessel
         Fragmented tools, no predictive analytics, no AI decision support

Slide 3: Solution
         PortMind AI — the unified AI operations control centre
         One screenshot of the dashboard

Slide 4: Key Features (5 features with icons)
         Risk Scoring | 72h Forecast | Crisis Simulation | Berth Optimisation | AI Copilot

Slide 5: Architecture
         Browser → api.js → Express API → JSON data
         Offline fallback diagram

Slide 6: Demo Highlights
         Screenshots: vessel modal, optimise berths panel, copilot response, report

Slide 7: IBM Technologies
         How IBM Bob was used — architecture, code generation, validation, documentation

Slide 8: Team & Hackathon Impact
         Team names, what each person built, what comes next
```
